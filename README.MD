# Professional Calculator

A modern and responsive calculator built using HTML, CSS, and JavaScript.  
This project performs all basic arithmetic operations with a clean user interface, keyboard support, and professional styling.

---

# Preview

Professional UI with:
- Responsive Design
- Modern Dark Theme
- Keyboard Support
- Real-Time Calculation
- Smooth Hover Effects

# Technologies Used

## HTML5
Used for:
- Structure of calculator

- Layout organization

## CSS3
Used for:
- Professional styling

# Features

## Arithmetic Operations
Supports:
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal calculations

---

## User Interface
- Professional design
- Dark modern theme
- Rounded buttons
- Interactive animations
- Large display screen

---

## Keyboard Support

| Key | Function |
|------|----------|
| 0-9 | Numbers |
| + - * / | Operators |
| Enter | Calculate Result |
| Backspace | Delete Last Character |
| Escape | Clear Display |

---

# Main Functions

## appendValue()
Adds numbers/operators to display.

## clearDisplay()
Clears complete screen.

## deleteLast()
Removes last entered character.

## calculateResult()
Calculates final result using JavaScript evaluation.
